## 二、每项习惯的完成条件(数据结构直接可用)

### H1 每天100字复盘
- **完成条件**:当日提交复盘文本 ≥ 100字(去除标点空格计数)。
- **一日一次**:每个自然日(用户本地时区)只算1次有效完成,重复提交覆盖当日记录,不重复计次。
- **补录**:可补写前3天以内的复盘,但补录**不发放积分/成长值**,仅作记录填补(呼应"补录不给分"防刷规则)。
- **模板字段**:今天做了什么决定 / 结果如何 / 下次想怎么改(三段式引导,不强制填满,填字数够100即可)。

### H2 30分钟深度思考
- **开始门槛(2026-08-05用户决策采纳)**:开始前需选一个当日推荐议题(3个)或填写自定义议题;不设跳过。
- **完成条件**:专注计时器从0跑满 **30分钟**且期间**暂停累计不超过5分钟**。
- **计时规则**:可暂停/继续,暂停时长计入统计但不计入"专注时长";超过累计暂停5分钟或用户主动"结束"未达30分钟 → 记为未完成,单独保存为一次失败的计时会话(不是有效完成日志,不发奖励)。
- **计时依据**:用时间戳计算经过时间,不依赖内存递减数字;App进入后台或界面重建后仍需能恢复正确时长。
- **一日一次**:每日只有第一次达标的计时记为当日有效完成。

### H3 每天一件让自己不舒服的事
- **完成条件**:从挑战卡池抽1张 → 用户可换卡 → 完成后点击"我做到了"确认。
- **换卡规则(2026-08-05用户决策采纳)**:每天最多3次换新卡;第4次起在当天前3张中循环切换,不再出新卡。
- **不做审核/证据要求**:纯自我承诺确认(呼应"对完成上瘾非对App上瘾",不加打卡截图等重负担)。
- **一日一次**。

### H4 睡前断网
- **版本(2026-08-05用户决策采纳大D版,取代原"轻仪式"口径)**:
  - 用户选 15/30/60 分钟开始仪式,开始后**无暂停**。
  - **离开检测**:离开页面或切出App,本次倒计时重置并记1次失败。
  - **失败后果**:连续3次失败 → 锁定10小时不能开始;锁定期满自动解锁。
  - **完成**:倒计时归零自动完成,记有效完成+1积分(取代原"手动确认")。
- **崩溃洞修复(合并main前必做)**:App启动时,把上次运行遗留的 running 态 H4 会话先判 failed 再展示,防止进程猝死(未触发生命周期回调)后重开白拿积分。
- **仍不做系统级强制锁**(不屏蔽其他App;真·系统级锁屏机制保留在 P2,见 [[project_habit_app]])。
- **一日一次**。

> 四项习惯**完成条件均为"当日true/false"**,不区分完成质量高低,不做部分完成分。这样成长值计算(第三节)可以统一用"有效完成次数"。

## 三、养成物成长规则(有效完成次数驱动,非连续天数)

### 3.1 计数口径（2026-08-06用户决策更新）
- 每个用户选择的习惯**各自独立**养一株养成物(不是4个习惯共用1株),对应"每站一片生态"的设计。
- 历史成长值 = 该习惯**有效完成次数累计**，只增不减，继续作为积分审计与完成历史事实。
- 当前养成进度 = 历史成长值减去历次休眠衰减，最低为0；当前成长阶段按当前养成进度判定。

### 3.2 阶段阈值
| 阶段 | 所需累计有效完成次数 |
|---|---|
| 种子 | 0 |
| 发芽 | 3 |
| 成长 | 10 |
| 开花 | 25 |
| 繁茂 | 60 |

### 3.3 中断、休眠衰减与恢复（2026-08-06用户决策更新）
- 休眠改为全局判定：连续 **7个完整自然日没有完成任何习惯**，在第7个未完成日24:00使所有当前养成物进入休眠视觉状态。刚启用当天不算未完成日。
- 第6个未完成日提前提示"再过1天没有完成习惯，养成物将进入休眠"；第7个未完成日提示"今天完成任一习惯，可避免养成物今晚进入休眠"。
- 休眠触发后，当前养成进度按每天 **1、2、1、2……** 的整数序列循环扣除，平均每天1.5点，最低扣至0；允许从繁茂/开花等阶段退回较早阶段，但不删除 HabitLog、不扣积分。
- 休眠后的第一次有效打卡立即进入恢复期并冻结衰减；完成 **3个不同自然日**的任意有效打卡即解除休眠，不要求连续，补录不计入；这些打卡正常增加对应习惯的历史成长值和当前进度。
- 恢复期间若再次连续7个完整自然日没有完成任何习惯，恢复计数清零，并从新衰减周期第1天（扣1点）重新开始衰减。
- 已经衰减的进度在解除休眠后不返还，新的有效完成从剩余当前进度继续叠加。
- **恢复加成上限**:若产品后续想给"回归奖励",加成封顶 = 当前所处阶段所需次数的 **30%**,不用固定值(呼应B版评审建议)。第一阶段先不做回归加成,仅做"解除休眠"这一动作,加成机制留待验证后再加。

### 3.4 防刷规则
- 补录记录(见H1)**不计入成长值、不发积分**。
- 每日每习惯**最多计1次**有效完成,重复点击/重复提交不重复发奖励(前端+后端双重判重,以当日日期+habitId为唯一键)。
- 成长值只对**用户自己启用的习惯**生效,不可通过临时启停习惯刷次数(启用状态变更不重置或多算历史次数,但暂停期间不产出新次数)。

### 3.5 积分(第一阶段最小口径)
- 每项习惯**每个自然日首次有效完成**获得 **1积分**。补录、未达标、重复提交均为 **0积分**。
- 积分记录(积分流水)必须与首次有效完成的打卡日志**同一数据库事务**内写入,不能只存余额、不留流水。
- 第一阶段**只做**积分获得记录 + 余额展示,**不做**积分商店、装扮兑换、施肥消耗等花费规则,留待商店迭代再定。

## 四、解锁条件(数值化)

### 4.1 首批习惯内部无解锁门槛
H1~H4 首发即选即用,不设解锁条件。

### 4.2 第二章解锁条件（2026-08-06用户决策更新）
- 触发条件:所有已选习惯的**历史有效完成总次数累计达到6次**；若同时选择并每天完成3个习惯，最快2天解锁。
- 达标后永久解锁，不因取消习惯或休眠衰减而重新上锁。判定使用不衰减、不删除的历史 HabitLog 总数。
- 解锁入口展示第二章徽章与文案"你已解锁下一段旅程"；点击后放大展示徽章，并提示"你现在可以选择新的习惯"。**第二章具体4个习惯的内容和交互第一阶段不实现**。
- 这是唯一需要在阶段2写的解锁判定逻辑,避免"必要时开放下一组"变成无法验证的抽象需求。

## 五、解锁路径视觉描述(飞行棋参考,仅展示,不含玩法规则)

- 路径为一条**横向或曲线排布的站点链**,共12个站点对应12个习惯,分3段(章),每段4站,视觉上用飞行棋的"格子连线"感(站点=圆形节点,节点间用线连接,不需要骰子/掷点/对战等游戏规则)。
- 站点状态3种:
  - **已解锁未开始**:节点亮色,未点亮光效。
  - **进行中**:节点显示当前成长阶段小图标(种子/发芽/成长/开花/繁茂对应的小图标)。
  - **锁定**:节点灰色,点击弹出解锁条件文案"累计完成6次习惯后解锁第二章"。
- 用户在路径上的位置**不代表"进度条百分比"**,只是习惯集合的展示地图,不做飞行器移动动画(那是叙事升级项,列入阶段4视觉完善,不在第一阶段实现范围)。

## 六、第一阶段全部文案

### 6.1 Onboarding(承诺锚点)
- 开场一句话:"选一个最难的习惯,今天开始,让它在你手里一点点长大。"
- 引导填空:"我想养成这个习惯,是因为______"(自由文本,存为 commitmentNote,后续可在设置里回看,不强制填写但强引导)。

### 6.2 H1 每天100字复盘
- 介绍:"每天花2分钟,写下一个决定、一个结果、一个改进。100字不用多,但要真。"
- 引导三问:"今天做了什么决定?" / "结果怎么样?" / "下次想怎么改?"
- 完成反馈语(随机3选1):"记下来了,这就是进步的证据。" / "又攒了一点复利。" / "今天的你,比昨天多想了一步。"

### 6.3 H2 30分钟深度思考
- 介绍:"放下手机,给自己30分钟不被打断的时间。想清楚一件真正重要的事。"
- 计时中提示:"专注中,先别看手机。"
- 完成反馈语:"30分钟,你刚刚给了自己一份最贵的礼物——注意力。"

### 6.4 H3 每天一件让自己不舒服的事
- 介绍:"舒适区外一小步,才是真正的成长区。"
- 挑战卡:不设首发条数硬指标,首版沿用已交付内容即可,是否够用由用户自行判断,后续可随时增补。示例5条:
  1. "给一个很久没联系的人发条消息。"
  2. "在会议/群里说出一个不一样的意见。"
  3. "拒绝一件你其实不想做的事。"
  4. "走一条没走过的路回家。"
  5. "对着镜子说一句你一直不敢承认的真话。"
- 完成反馈语:"不舒服的那一下,就是你在变强的证据。"

### 6.5 H4 睡前断网
- 介绍:"给大脑一个真正安静的收尾,而不是刷到睡着。"
- 仪式开始文案:"接下来30分钟,试着不碰手机。倒计时开始。"
- 倒计时结束文案:"仪式完成了吗?"(用户点确认)
- 完成反馈语:"今晚,你比手机先睡着的样子,很好看。"

### 6.6 养成物阶段文字描述(第一版,统一模板,不分习惯情绪差异)
| 阶段 | 描述文案 |
|---|---|
| 种子 | "一颗还没发芽的种子,在等你第一次坚持。" |
| 发芽 | "冒出了第一片叶子,是你这几天攒下来的。" |
| 成长 | "长出了茎干,能感觉到它在往上够。" |
| 开花 | "开花了。这是你陪它走过25次的样子。" |
| 繁茂 | "枝繁叶茂,像极了坚持很久之后的你。" |
