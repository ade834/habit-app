## 一、目标与原则

- 目标：给 App 一套与"治愈系/清爽/后花园"一体的视觉语言；养成物页从"数据卡片"升级为"互动花园"。
- 原则1（可视化优先）：数据隐藏后台，用户只看到视觉。成长阶段、积分、次数均不以数字/进度条裸露；一切状态经由植物形态传达。
- 原则2（微动态）：动效服务于"活着"的感觉——常驻微动（摇摆、呼吸、露光），触碰互动（抖露水、侧首、开花摆手）。克制，不喧哗。
- 原则3（一致）：所有页面图标、卡片、徽章同属一套视觉体系，不出现风格孤儿。
- 原则4（性能/包体）：植物与图标用 SVG/矢量 + 代码动效，默认禁止引入视频与 3D 引擎。

## 二、技术选型（统一口径，回答此前 Three/Node/视频疑问）

| 方案 | 是否采用 | 原因 |
|---|---|---|
| Three.js | 否 | Web 3D 库，Flutter 用不了 |
| Node.js | 否 | 后端技术，与渲染无关 |
| 预生成视频(MP4/GIF) | 否 | 不可按状态切换、不可触摸交互、包体大 |
| Lottie(.json) | 以后可选 | 需要 AE 产出文件；本阶段不引入外部工具依赖 |
| Rive(.riv) | 以后可选 | 需要 Rive 编辑器；本阶段不引入 |
| **SVG 矢量 + Flutter 代码动效** | **本阶段采用** | 轻量、可交互、Both 可闭环；植物多姿态 + 过渡动画 |

→ 植物、图标、徽章全部用 SVG 提供静态姿态（发芽/生长/开花/枯萎各一姿态），由一个 Flutter 动效层做姿态间的过渡与触摸反应。

## 四、Part A 交付物详情（大C 负责）

### A1 视觉方向（先做，等用户挑）
交付 ≤4 版方案，各自包含：
- 完整色板（4-6 个具名 HEX + 用途）
- 字体选择（展示体/正文字/标注字）
- 组件质感（圆角半径、卡片背景、分割线、阴影/无阴影）
- 图标风格（线稿/圆角填充/描边粗细）
- 一个示例页 HTML 原型（今天页或习惯列表页）可直接浏览器打开
- 一句话承诺："这一版给你的是___感觉"

风格基调参考：治愈系、清爽、低饱和、留白、纸张/晨露感；最终依据用户参考图收敛。

### A2 SVG 资产（风格选定后批量产出）
- 12 个习惯图标：与整体风格同源；含义直接对应习惯主题（H1 复盘=镜/日记；H2 专注=旗帜/树荫；H3 挑战=骰子/含羞草；H4 断网=月亮/停驻——以最终方向为准）。
- 成就徽章整套：统一版式（圆章/吊牌/花型），金银铜或植物色系分级。
- 植物 SVG：12 种植物 × 4 姿态（种子/发芽/开花/枯萎/休眠/繁茂 详见 Part B 映射）。

### A3 内容定义（Draft，待用户确认）
徽章触发清单（建议首期 10 枚，可删改）：
1. 初见——完成第一个习惯（任意）
2. 晨露——同一习惯连续 3 个自然日
3. 满月——连续 7 天有完成
4. 新芽——任一习惯累计完成 10 次（成长）
5. 绽放——任一习惯累计完成 25 次（开花）
6. 繁茂——任一习惯累计完成 60 次（繁茂）
7. 静界——完成一次 H4 断网仪式
8. 远行——完成一次 H11 独自旅行
9. 星辉——完成一个星标习惯
10. 万物生——全部已选习惯各完成 ≥1
（触发均由现有 HabitLogs/points 派生，无需新表；"解锁第二章"等特殊里程碑可后续追加）

空状态文案示例："种子还在土里，等你的第一次浇水。"（不写数字，只给画面与引导）

## 五、Part B 交付物详情（大D 负责）

### B1 主题
- 按选定方案建 `theme`（colors/typography/shadows），全部页面改用 Theme 引用，移除散落硬编码色值。

### B2 资产接入
- 接收大C 的 SVG 目录（`assets/plants/`、`assets/icons/`、`assets/badges/`），注册 pubspec。

### B3 动效层（后花园）
植物状态映射（数据→形态，数据隐藏原则）：
| 成长数据 | 植物形态 |
|---|---|
| 未选/未启用 | 不显示 |
| 种子（<3 次） | 泥土+种子 |
| 发芽（3-9） | 小芽 |
| 成长（10-24） | 茎叶 |
| 开花（25-59） | 开花 |
| 繁茂（≥60） | 繁茂/结果 |
| 休眠（7 天未完成） | 枯萎垂头 |
| 解除休眠（3 个自然日完成） | 恢复形态 |
- 姿态间用 600-900ms 缓动过渡；常驻微动（±2° 摇摆/呼吸缩放）。
- 触摸：Tap → 整株轻微摇晃 + 露珠滑落/花侧首一次；长按不占滚动。
- 12 种植物（建议对应表，可改）：
  H1 朝颜 / H2 向日葵 / H3 含羞草 / H4 茉莉 / H5 藤蔓 / H6 迷迭香 / H7 多肉·钱串 / H8 蕨 / H9 铃兰 / H10 白桦 / H11 蒲公英 / H12 三叶草
- 布局：花园页"边框生长"，植物沿花园边框/围栏排列，中部留白或池塘/小路点缀；所有花园视觉在画布层绘制，与数据层解耦。

### B4 徽章系统
- 达成判定：由现有数据派生（habitLogs/points/次数），无新表；达成瞬间播放"获得徽章"轻动效 + 红点提示。
- 收藏盒：花园内一个可点开的小盒子（木箱/花箱），打开弹出徽章册：已获得彩色、未获得剪影锁定；宫格展示。

### B5 数据隐藏
- 今天页/养成物页不显示：积分数字、完成次数、进度百分比、阶段阈值；以视觉形态与轻量文案（"刚浇过水""它今天很开心"）代替。
