# 当前迭代：阶段1 关闭 → 阶段2 核心正反馈循环

## 当前目标
实现"完成习惯→记录→积分→养成物成长→阶段进度→解锁判定"的完整闭环，四个习惯各自的最小可用打卡交互。

## 本阶段范围
- 四个习惯的最小打卡交互：H1复盘编辑器(三段式+100字计数) / H2计时器(30分钟、暂停上限5分钟、时间戳计时) / H3挑战卡(抽卡、换一次、确认完成) / H4断网仪式(15/30/60选择、倒计时、确认完成)
- 单一事务：有效完成日志+积分流水原子写入；每习惯每日首次有效完成=1积分
- 防重：当日 habitId+localDate 唯一约束，重复提交0积分
- 补录：仅H1可补前3个自然日，只记录不积分
- 养成物成长：阶段阈值 种子0/发芽3/成长10/开花25/繁茂60，全部派生计算不冗余存储
- 休眠与恢复：7天未有效完成进休眠；3个不同自然日有效打卡解除
- 第二章解锁判定：任一已选习惯达开花(25次)→路径上第二章锁变可点击(仅视觉状态+提示文案)
- 打卡即时微反馈(轻量动画/触觉即可，不追求美术)

## 不做什么
- 积分商店/装扮兑换/消耗规则
- 联网AI复盘、旅行模块、第二养成主题、系统级断网强制锁
- 视觉完善(阶段4)：iPad内容最大宽度、设置页提醒/隐私区等已知小账

## 验收条件
- 四个习惯各走一次完整打卡，积分+1且流水可查
- 连点/重复提交只发1积分
- 补录(H1)有记录但0积分
- 成长阶段按阈值正确推进，中断不清零不倒退
- H2计时后台/重启后时长仍正确
- 退出重开数据全在
- 自动测试覆盖：防重、补录不积分、阶段阈值、休眠恢复
- 大C体验评审 + 用户真机验收
