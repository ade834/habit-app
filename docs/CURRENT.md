# 当前迭代：阶段3 —— 复盘月历记录窗口

## 当前目标
阶段2核心正反馈循环与补齐功能已合并 `main`。阶段3实现复盘板块的只读月历记录窗口，从现有日志、复盘、计时和挑战记录派生每日汇总。

## 本阶段范围
- 四个习惯的最小打卡交互：H1复盘编辑器(三段式+100字计数) / H2计时器(30分钟、暂停上限5分钟、时间戳计时、开始前选/填议题) / H3挑战卡(抽卡、每天3次新卡后循环、确认完成) / H4断网仪式(15/30/60、无暂停、真正离开页面才重置、通知中心/控制中心/锁屏/后台不打断、连续3次锁10小时、归零自动完成)——H2/H3/H4规则按用户最新决策采纳，详见规格
- **已完成合并main前置项**：App启动时先把遗留running态H4会话判failed，再展示页面；见 reviews/03 问题3
- 单一事务：有效完成日志+积分流水原子写入；每习惯每日首次有效完成=1积分
- 防重：当日 habitId+localDate 唯一约束，重复提交0积分
- 补录：仅H1可补前3个自然日，只记录不积分
- 养成物成长：阶段阈值 种子0/发芽3/成长10/开花25/繁茂60；历史完成与当前养成进度分开派生
- 全局休眠与恢复：连续7个完整自然日没有完成任何习惯，在第7天24:00进入休眠；休眠后按1/2点交替逐日衰减；首次恢复打卡立即冻结衰减，3个不同自然日有效打卡解除；恢复期再次断档7天则恢复计数清零并重启衰减
- 第二章解锁判定：所有习惯历史有效完成总计6次后永久解锁；入口展示徽章与新习惯提示，休眠衰减或取消习惯不重新上锁
- 调试构建：设置页提供每个已选习惯+1/+5测试点；Release不展示，正式发布前彻底删除
- 打卡即时微反馈(轻量动画/触觉即可，不追求美术)

## 不做什么

- 联网AI复盘、旅行模块、第二养成主题、系统级断网强制锁

## 验收条件
- 四个习惯各走一次完整打卡，积分+1且流水可查
- 连点/重复提交只发1积分
- 补录(H1)有记录但0积分
- 成长阶段按阈值正确推进；休眠衰减可使当前阶段后退，但不删除历史完成、积分或第二章解锁状态
- H2计时后台/重启后时长仍正确
- 退出重开数据全在
- 自动测试覆盖：防重、补录不积分、阶段阈值、休眠预警/衰减/恢复、第二章永久解锁、H4冷却重置
- 大C体验评审 + 用户真机验收

## 阶段3范围

- 在“复盘”板块增加日历记录窗口。
- 月历按天显示习惯完成汇总，点击日期查看当天详情。
- 详情包含：完成的习惯、获得积分、H1复盘内容、H2专注时长/成败状态、H3当天挑战卡、H4时长与重置结果。
- 日历默认只读；H1历史补录仍只允许前3天。
- 汇总优先从现有日志和工具记录派生，不重复存储一份汇总数据。
- 只读月历按月切换；当天有完成时显示热力深浅。
- 点击日期查看完成习惯、积分、H1内容、H2时长与成败、H3挑战卡、H4时长与重置结果。
- 月历下方显示月度总结：习惯完成次数柱状图、最容易坚持/放弃的习惯、完成习惯对应的人生进步方向和本地鼓励文案。
- 不在日历窗口中新增编辑入口；H1历史补录规则继续由H1工具控制，仅允许前3天。
