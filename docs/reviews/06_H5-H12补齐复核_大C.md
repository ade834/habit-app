## 二、按验收点核验（通过）

### 2.1 月历同一天最多 3 条短标题 —— 通过
- `app/lib/ui/habit_app.dart` `_CalendarDay` 内 `for (final activity in summary.calendarActivities)`，每条 `maxLines: 1` + `TextOverflow.ellipsis`；`calendarActivities` 截取前 3。功能与裁定一致。
- 测试 `月历最多显示3条活动短标题`（test:29）断言 4 条输入只出前 3 条。

### 2.2 H7 非数字输入提示且不保存 —— 通过
- `_save()`（`app/lib/ui/habit_tools_page.dart:71`）：任一数字字段非空且非数字 → SnackBar“资产投入和消费消耗仅能填写数字，也可留空。”并 return，不写库。
- 空串放行（选填语义保留）；键盘 `numberWithOptions(decimal: true)` + helperText“选填，只能填数字”。
- 测试 `H7财务字段仅允许选填数字`（test:51）覆盖空、数字、中文三类输入。

### 2.3 星标/周期额外名额：首次选择 / 次日 / 更换习惯 一致 —— 通过
- 唯一判定入口 `countsTowardsRegularQuota`（`app/lib/domain/habit.dart:41`）：星标 → 不占；周期习惯且 `enabledAt` 为今天 → 占（首日），否则不占（次日及以后）。
- 三个场景走同一函数，规则自洽：
  - 首次选择：`enabledAt=当前` → 当天占普通名额。
  - 次日：`enabledAt` 为前一天 → 不占，自动转额外。
  - 更换习惯：`replaceSelectedHabits`（`app_database.dart:205`）换出的习惯删行，重新加入时 `enabledAt` 重置为当天（视作新的首日、当天占名额）；持续持有的习惯保留原 `enabledAt`（次日转额外不加天数）。无分叉逻辑。
- 名额强度：数据层 `regularCount > 3` 抛错（app_database.dart:226），UI 对话框实时计数 `已选：普通 n/3`（habit_app.dart:432）。既有的首次/次日两条测试走此强度路径（若判定错会抛错失败），语义被隐式覆盖。

### 2.4 H4 "锁屏/切 App 不失败" 未被回退 —— 通过
- `didChangeAppLifecycleState`（`app/lib/ui/habit_tools_page.dart:841`）仍只在 `resumed` 时 setState 重建；锁屏、通知中心、控制中心、切 App、后台均不判失败。
- 失败来源仍仅为：离开 H4 工具页（dispose 结束未完成会话）与 App 重启后遗留 running 会话判失败。

## 三、非阻塞建议

- **N1（真机验收前建议顺手处理）** 日历格子垂直空间：`_MonthCalendar` 的 `GridView.count` 默认 `childAspectRatio: 1.0`（格子高=宽）。iPad 宽度下 3 行放得下；窄屏（iPhone ~390pt，格子约 46×46）下“日期 + N项 + 3 行”会垂直溢出（debug 红黄条）。建议给 GridView 设 `mainAxisExtent` 或放宽纵横比、或压缩标题行高。（`app/lib/ui/habit_app.dart` ~1100）
- **N2** 展示的 3 条为 `habitActivityEntries` 的插入序（查询无 ORDER BY，`app_database.dart:790`），即当日“最早完成”的 3 条而非最新。若产品希望最新优先，补 `completedAt` 排序一行即可；详情页仍显示全部，可后续再定。
- **N3** 测试覆盖表述：handoff/CURRENT.md 写“首次选择/次日/更换习惯三场景自动测试”覆盖，实际 test:71/86 是隐式覆盖（经写入强度路径随路断言）；“更换习惯”（换出→再换入周期习惯）没有对 quota 语义的显式断言。建议补一条显式断言（换出次日换回=占名额 / 持续持有次日=不占），或收敛文档措辞。不影响本次验收。
- **N4** `isOptionalNumber` 用 `double.tryParse`，会放过 `1e3`、`+5`、`NaN`、`Infinity` 等写法（手机数字键盘基本打不出，危害极低）。如需更严格可用 `^\d+(\.\d+)?$`。可选。
- **N5** H7 `_primary` 为空仍静默 return（维持原状，不属本轮范围）；若想统一可对主文本也给提示。可选。
