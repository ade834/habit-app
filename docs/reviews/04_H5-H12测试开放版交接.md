# H5–H12 测试开放版交接

## 目标分支

`feature/stage3-local`

## 评审范围

本轮将 H5–H12 预实现为测试可见版本，暂不确定正式章节、开放节奏和解锁条件。H1–H4 原有规则保持不变。

## 重点变化

- H1–H12 均可见、可选择；普通习惯最多 3 项，星标习惯从首次选择起即为额外项；H5/H7/H10/H11 在首次选择当天计入普通名额，次日起转为额外项。
- 星标习惯完成时积分流水为 0，但仍写入 HabitLog、增加历史完成次数和养成进度，并进入复盘日历。
- 选择对话框显示普通/星标计数；普通项超过 3 个时禁用保存，并提示先将额外项设为星标。
- H5–H12 使用本地结构化记录；周期内可暂存到后续日期完成。
- 积分倍率为：每日/自建 1、每周 3、每月 4、每年 99。
- 完成任务后直接返回上一页，并在顶部显示积分提示。
- 日历格只显示 5 个字以内的短标题，超出显示 `...`；日期详情显示完整内容。
- H11 第一次进入创建离线旅行向导计划，第二次进入填写旅行总结并完成。
- 旅行天数使用 1–30 天滚轮。

## 已验证

- `flutter analyze` 通过。
- 40 项自动测试通过，包含星标习惯 0 积分、成长 +1，以及首次星标不占名额、周期习惯次日转额外名额的真实数据路径验证。
- Xcode 27 iOS Simulator Debug 构建通过，并已安装、启动到 iPad Air 13-inch (M4) 模拟器（`A3A94B17-1949-4B99-A851-D0A3F2CBF50A`）。

## 请审核

- 短标题长度和日历信息密度是否合适。
- 周/月/年任务“周期内暂存”的语义是否符合产品预期。
- 1/3/4/99 积分倍率是否需要调整。
- H11 两次进入的旅行向导 → 总结流程是否自然。
- H5–H12 当前最小工具字段是否足够支撑后续正式开放。
- “普通 3/3 · 星标 n”计数、星标按钮和超限提示是否足够清楚。
