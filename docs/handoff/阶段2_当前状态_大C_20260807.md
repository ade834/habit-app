## 三、H4 断网仪式 · 最终规则（用户 2026-08-06 拍板，**本次复核核心**）

| 场景 | 生命周期 | 结果 |
|---|---|---|
| 下拉通知中心 / 控制中心 | `inactive`（瞬态） | **不打断** |
| 锁屏（iOS 上停在 `inactive`） | `inactive` | **不打断** |
| **切到另一个 App / 回桌面 / 后台** | `paused` | **记失败** |
| App 内离开本页面 | `dispose` | 记失败（已有） |
| 连续 3 次失败 | — | 锁 10 小时 |
| 时间到点 | — | 自动完成 +1 分 |

**修法（给大D）**：`didChangeAppLifecycleState` 只在 `paused`（或 `hidden`/`detached`）判失败；`inactive` **不判失败**。iOS 锁屏停在 inactive 不会触发 paused，故可同时满足"锁屏不打断"与"切走失败"。项目 iOS 优先，Android 锁屏是否触发 paused 需大D 在目标平台验证。

**背景**：大D 提交 `0d1db1f` 把"切到另一个 App / 回后台"也一并放行了 → 用户可切走刷手机、到点自动 +1，"断网"约束失效 → 用户拍板修正为"切走/回后台 = 失败"。

**必补测试**：切到后台/另一 App → 判 fail 计入连续失败；拉通知中心/锁屏 → 不计 fail、倒计时不被重置。
