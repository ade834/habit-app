## 四、问题清单（重点）

**问题A（中）H4冷却期后连击计数未真正重置**
- 现象：冷却到期只把显示计数归零，DB 里3条 failed 还在；冷却后再失败1次（无成功间隔）即重新锁10h，与"连续3次失败→锁定"不符。
- 修法：冷却到期视为计数重置点，只统计最近一次 completed 之后、落在未过期冷却窗口内的失败。
- 必补测试：3次失败→锁到期→再失败1次→仍为"第1次失败"。

**问题B（已拍板：本轮补齐）多阶段成长 + 休眠 + 第二章解锁【未实现】**
- 阶段阈值：种子0 / 发芽3 / 成长10 / 开花25 / 繁茂60（5段文案在规格6.6）。
- 休眠：7天未有效完成→休眠视觉（不消失不清零）；起点=max(启用日, 最后一次完成日)起算7天。
- 解除休眠：3个不同自然日有效打卡；补录不计入；这3次正常计累计次数。
- 第二章解锁：任一已选习惯达开花(25)→第二章锁变可点击 + 提示文案，内容不实现。
- 全部**派生计算、不新增表**；当前无"路径"页，放置位置建议落地到养成物页/习惯页。

**问题C（低）** H4 在 inactive（拉通知栏/控制中心）即判失败，可能误杀 → 可后移阶段4。
**问题D（低）** 打卡即时微反馈仅 SnackBar，无触觉/动画 → 后移阶段4。
