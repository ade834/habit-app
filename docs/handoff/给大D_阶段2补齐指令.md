## 一、问题A修复（中）：H4 冷却期结束后连击计数未真正重置

> **【2026-08-07 更新：本节问题A 已由 `4e2ccbd` 修复，无需再改。】** 现版 `_disconnectAttemptState` 已改为升序 + `lockedUntil` 过期重置：冷却到期后再次失败会先清零旧计数再计 1，不再"新1+旧2=3"立即再锁。本节仅作历史记录，大D 可跳过问题A，直接做"一·五 H4 生命周期最终定稿"。

**现象**：`watchDisconnectAttemptState()` 从最新往旧数 failed、遇到 completed 才 break。连续3次失败→锁10h，锁到期后该方法只把返回的 `consecutiveFailures` 置 0（显示层归零），但 DB 里这 3 条 failed 记录仍在。若用户冷却到期后、尚无成功的情况下再次离开失败 1 次，计数变成"新1+旧2=3"→ 立即再次锁 10h。

**期望**：冷却 10h 到期应视为一次计数重置点，之后需**重新连续**失败 3 次才再锁。

**修法建议（任选其一，以语义正确为准）**：
1. 冷却到期时，把已过期的 failed 记录视为不计（例如只统计最近一次 completed 之后、且落在当前未过期冷却窗口内的失败）；
2. 或锁到期时清理/忽略旧 failed 轨迹。

**必补测试**：3次失败→锁到期→再失败1次→状态仍为"第1次失败"（不立即锁）。

**涉及文件**：`app/lib/data/app_database.dart`（`watchDisconnectAttemptState`）、`app/lib/domain/habit_tools.dart`（`DisconnectAttemptState`）。

## 一·五、H4 生命周期规则最终定稿（用户 2026-08-06 追加拍板，务必实现）

`0d1db1f` 把 H4 改成"后台/锁屏/通知中心都不打断"，但**把"切到另一个 App / 回后台"也一并放行了**——用户开始仪式后切走刷手机，时间戳到点仍会自动完成 +1，"断网"约束失效。用户已拍板最终规则：

| 场景 | 生命周期 | 处置 |
|---|---|---|
| 下拉通知中心 / 控制中心 | `inactive`（瞬态） | **不打断**（保留） |
| 锁屏（iOS 上为 `inactive`） | `inactive` | **不打断**（保留） |
| **切到另一个 App / 回桌面 / 后台** | `paused` | **记失败**（新增/修正） |
| 在 App 内离开本页面 | `dispose` | 记失败（已有，保留） |
| 连续 3 次失败 | — | 锁 10 小时（不变） |
| 时间到点 | — | 自动完成 +1 分（不变） |

**修法**：`didChangeAppLifecycleState` 只在 `paused`（或 `hidden`/`detached`，即真正切入后台）时 `endTimerEarly` 判失败；`inactive` **不判失败**。iOS 锁屏停在 `inactive` 不会立即 `paused`，故"仅在 paused 判失败"可同时满足"锁屏不打断"与"切走失败"；Android 锁屏是否触发 `paused` 需在目标平台验证（项目 iOS 优先，Android 后续适配）。UI 文案同步区分"下拉/锁屏不打断"与"切到其他 App 会失败"。

**必补测试**：切到后台/另一 App → 判 fail 并计入连续失败；拉通知中心/锁屏 → 不计 fail、倒计时不被重置。

## 二、问题B补齐：养成物多阶段成长 + 休眠/解除休眠 + 第二章开花解锁

按 `docs/product/01_第一阶段产品规格.md` 第三节与 `docs/CURRENT.md` 实现，均为**派生计算，不新增冗余表**（数据从 `HabitLogs` 与 `HabitSelections.enabledAt` 派生）。

### 2.1 多阶段成长（替换当前仅"种子/发芽"的写死逻辑）
- 成长值 = 该习惯**有效完成次数累计**（从 `habitLogs` 计数派生，不要求连续，中断不清零不倒退）。
- 阶段阈值：**种子 0 / 发芽 3 / 成长 10 / 开花 25 / 繁茂 60**。
- 养成物页（`_GrowthTile`）按阈值显示 5 个阶段及对应阶段文案（规格 6.6）：

| 阶段 | 阈值 | 文案 |
|---|---|---|
| 种子 | 0 | "一颗还没发芽的种子，在等你第一次坚持。" |
| 发芽 | 3 | "冒出了第一片叶子，是你这几天攒下来的。" |
| 成长 | 10 | "长出了茎干，能感觉到它在往上够。" |
| 开花 | 25 | "开花了。这是你陪它走过25次的样子。" |
| 繁茂 | 60 | "枝繁叶茂，像极了坚持很久之后的你。" |

- 进度条按"当前阶段内已达标程度"或"距下一阶段"合理呈现即可，不做美术（阶段4视觉完善）。

### 2.2 休眠与解除休眠
- **进入休眠**：连续 **7 天未有效完成**该习惯 → 养成物进入休眠视觉态（变灰/低垂，**不消失、不清零**）。
- **休眠起点** = `max(习惯启用日期 enabledAt, 最后一次有效完成日期)` 起算 7 天；刚启用当天不会立即休眠。
- **解除休眠**：完成 **3 个不同自然日**的有效打卡（浇水）即解除、恢复正常显示；不要求连续；**补录不计入这 3 次**（补录本就产生 HabitLog，天然满足）；这 3 次仍正常计入累计有效完成次数，不额外扣减/加成。
- 解除休眠的 3 次计数，用 `HabitLogs` 唯一键 `{habitId, localDate}` 的不同自然日派生即可，不新增表。

### 2.3 第二章开花解锁
- **触发条件**：任一**已选习惯**累计有效完成次数达到 **开花（25 次）**。
- **达成后**：第二章锁定图标变为"可点击查看详情"态，提示文案"你已解锁下一段旅程"。
- **只做解锁判定 + 视觉状态 + 提示文案，不实现第二章具体的 4 个习惯内容**（内容阶段6再做）。
- 放置位置说明：当前 App 五个 Tab（今天/习惯/养成物/复盘/设置）里**尚无"路径/飞行棋"页**（规格第五节描述的路径视觉未实现）。请把"第二章解锁"这一状态最自然地落到**现有页面**（建议养成物页或习惯页加一个"第二章"入口位，锁→解锁的视觉切换 + 提示文案），并保持最小实现；若你认为需要单列说明，请在回复里标注。
